## Overview

This document collects the diagnosis, recommended algorithmic/software changes, a corrected script and practical guidance for improving IMU-based position estimation and gesture tracking using an ESP32 + MPU6050 setup.

It was generated from the assistant's analysis and edits performed on the uploaded file `imu_pos_upd.py`.

---

## 1) Quick diagnosis — why position drifts and big lines appear

* **Double/inaccurate integration of acceleration.** IMU acceleration noise and any small bias produce large drift after two integrations.
* **Gravity subtraction errors** caused by small orientation errors (Madgwick has some drift, yaw especially without magnetometer) — wrong gravity → wrong motion acceleration.
* **HPF & smoothing implementation bugs** in the script (HPF placeholder and a no-op velocity smoothing) mean bias and low-frequency errors aren’t removed properly.
* **No bias estimation.** Gyro and accel biases change with temperature and time; not estimating them leads to drift.
* **Sampling irregularities** — use of raw timestamps is good, but integration method should be trapezoidal to reduce numeric error.
* **Spikes / outliers** from sensor or serial transmission cause long straight lines on plots (one spike integrated becomes a long displacement).
* **MPU6050 has no magnetometer** — yaw will drift; orientation errors project into acceleration after rotating to world frame.

---

## 2) Recommended algorithmic & software changes (high-value, implementable)

1. **Fix obvious code bugs**

   * Correct the HPF implementation (use previous values correctly).
   * Fix velocity smoothing — the previous no-op must become a proper exponential smoothing.

2. **Trapezoidal integration**

   * Use trapezoidal rule for integrating acceleration → velocity (and velocity → position). This reduces numeric integration error.

3. **Estimate biases online using ZUPT**

   * When ZUPT detects stationary, update gyro and accel bias estimates using a small-leak low-pass. Subtract these biases from the measurements before integration.
   * Keep accel bias in **world frame** (so gravity removal and bias are consistent).

4. **Better stationarity test**

   * Replace single-sample thresholds with a *small windowed* statistic (e.g., RMS of gyro and accelerometer magnitude over 50–200 ms). This reduces false positives/negatives.

5. **Outlier/spike filtering**

   * Apply a short median filter or simple outlier clamp on raw accel and gyro before fusion.

6. **Filter design: augment Madgwick with bias estimation or switch to an EKF**

   * Madgwick gives good orientation quickly but does **not** estimate gyro/accel biases. Consider an EKF/UKF or an INS-type filter with state `[q, v, p, gyro_bias, accel_bias]` for best results. If that’s too heavy, bias correction via ZUPT is still very effective.

7. **Add motion constraints for gestures**

   * If gestures are constrained (e.g., mostly in a plane or within fixed distance), enforce those constraints to reduce drift (project motion to XY plane, clamp unrealistic velocities).

8. **For yaw drift / orientation stability**

   * Use an IMU with magnetometer (MPU9250 or external magnetometer) if you can — it helps yaw stability which helps gravity subtraction. Otherwise rely more on ZUPT and pattern recognition.

9. **Gesture recognition layer**

   * Don’t rely solely on integrated position for gestures. Build a classifier using orientation & gyro features (quaternions, angular velocity, short-time FFT, peaks, etc.). Template matching (DTW), random forest, or a small CNN on windows will be robust and far easier than perfect position tracking.

## 3) Edited / corrected script (drop-in replacement)

```python
# imu_pos_upd_fixed.py
# Edited & annotated version with:
# - correct HPF
# - trapezoidal integration
# - gyro/accel bias estimation using ZUPT
# - median spike filter
# - fixed velocity smoothing
# - windowed stationarity detection
#
# Based on the original uploaded file (imu_pos_upd.py)

import serial, math, numpy as np, collections, time
import pyqtgraph as pg
import pyqtgraph.opengl as gl
from pyqtgraph.Qt import QtCore, QtWidgets
from pyqtgraph.Qt.QtGui import QMatrix4x4
from ahrs.filters import Madgwick

# ---------------- USER CONFIG (tune these) ----------------
PORT = 'COM7'
BAUD = 115200
GYRO_IN_DEG = True      # Arduino outputs deg/s
BETA = 0.25
INITIAL_SAMPLE_HZ = 100.0
MAX_POINTS = 800

# ZUPT / stationarity params
ZUPT_GYRO_THRESH = 1.5     # deg/s (raw units)
ZUPT_ACCEL_THRESH = 0.12   # m/s^2 (magnitude error from 9.81)
ZUPT_WINDOW_SEC = 0.15     # use windowed RMS for stability test

# filters / smoothing
HPF_ALPHA = 0.995
VEL_SMOOTH = 0.85
BIAS_ALPHA = 0.995         # bias leakage (closer to 1 => slower update)
MEDIAN_WINDOW = 3          # median filter window (odd)
SPIKE_CLAMP = 50.0         # clamp improbable accel values (m/s^2)

# visualization update
GUI_UPDATE_MS = 12

# ---------------------------------------------------------

ser = serial.Serial(PORT, BAUD, timeout=0)
time.sleep(1.0)

# --- GUI setup (kept similar) ---
app = QtWidgets.QApplication([])
win = pg.GraphicsLayoutWidget(show=True, title="IMU Position (Madgwick + ZUPT, Fixed)")
win.resize(1200, 900)

p1 = win.addPlot(title="Acceleration (m/s²)"); p1.addLegend()
curve_ax = p1.plot(pen='r', name='ax'); curve_ay = p1.plot(pen='g', name='ay'); curve_az = p1.plot(pen='b', name='az')
win.nextRow()
p2 = win.addPlot(title="Gyroscope (deg/s)"); p2.addLegend()
curve_gx = p2.plot(pen='r', name='gx'); curve_gy = p2.plot(pen='g', name='gy'); curve_gz = p2.plot(pen='b', name='gz')
win.nextRow()
p3 = win.addPlot(title="Orientation (deg)"); p3.addLegend()
curve_roll = p3.plot(pen='r', name='roll'); curve_pitch = p3.plot(pen='g', name='pitch'); curve_yaw = p3.plot(pen='b', name='yaw')
win.nextRow()
p4 = win.addPlot(title="Position XY (m)"); p4.setAspectLocked(True)
curve_xy = p4.plot(pen=pg.mkPen('w', width=2))

# 3D cube
w3d = gl.GLViewWidget(); w3d.setWindowTitle('Orientation Cube'); w3d.setCameraPosition(distance=10, azimuth=30, elevation=20)
axis = gl.GLAxisItem(); axis.setSize(3,3,3); w3d.addItem(axis)
w3d.show()

# buffers & state
t_buf = collections.deque(maxlen=MAX_POINTS)
ax_buf = collections.deque(maxlen=MAX_POINTS)
ay_buf = collections.deque(maxlen=MAX_POINTS)
az_buf = collections.deque(maxlen=MAX_POINTS)
gx_buf = collections.deque(maxlen=MAX_POINTS)
gy_buf = collections.deque(maxlen=MAX_POINTS)
gz_buf = collections.deque(maxlen=MAX_POINTS)
roll_buf = collections.deque(maxlen=MAX_POINTS)
pitch_buf = collections.deque(maxlen=MAX_POINTS)
yaw_buf = collections.deque(maxlen=MAX_POINTS)
px_buf = collections.deque(maxlen=MAX_POINTS)
py_buf = collections.deque(maxlen=MAX_POINTS)

madgwick = Madgwick(beta=BETA, sampleperiod=1.0/INITIAL_SAMPLE_HZ)
q = np.array([1.0, 0.0, 0.0, 0.0])
last_time = None

# motion state
vel = np.zeros(3, dtype=float)
pos = np.zeros(3, dtype=float)

# HPF & integration state
hpf_state = np.zeros(3, dtype=float)
prev_a_motion = np.zeros(3, dtype=float)
prev_a_hpf = np.zeros(3, dtype=float)

# bias estimation (world frame for accel bias)
accel_bias_world = np.zeros(3, dtype=float)
gyro_bias = np.zeros(3, dtype=float) # rad/s bias for Madgwick input

# median filter history
med_ax = collections.deque(maxlen=MEDIAN_WINDOW)
med_ay = collections.deque(maxlen=MEDIAN_WINDOW)
med_az = collections.deque(maxlen=MEDIAN_WINDOW)
med_gx = collections.deque(maxlen=MEDIAN_WINDOW)
med_gy = collections.deque(maxlen=MEDIAN_WINDOW)
med_gz = collections.deque(maxlen=MEDIAN_WINDOW)

# windowed energy for ZUPT
zupt_window = collections.deque(maxlen=int(max(1, ZUPT_WINDOW_SEC * INITIAL_SAMPLE_HZ)))
zupt_time_window = collections.deque(maxlen=int(max(1, ZUPT_WINDOW_SEC * INITIAL_SAMPLE_HZ)))

# Utility functions
def quat_to_euler_deg(q):
    w, x, y, z = q
    roll = math.degrees(math.atan2(2*(w*x + y*z), 1 - 2*(x*x + y*y)))
    s = max(-1.0, min(1.0, 2*(w*y - z*x)))
    pitch = math.degrees(math.asin(s))
    yaw = math.degrees(math.atan2(2*(w*z + x*y), 1 - 2*(y*y + z*z)))
    return roll, pitch, yaw

def cube_set_quat(q):
    # keep simple, transform matrix from quaternion
    w, x, y, z = q
    R = np.array([
        [1-2*(y*y+z*z),   2*(x*y - w*z),   2*(x*z + w*y), 0],
        [2*(x*y + w*z),   1-2*(x*x+z*z),   2*(y*z - w*x), 0],
        [2*(x*z - w*y),   2*(y*z + w*x),   1-2*(x*x+y*y), 0],
        [0,0,0,1]
    ], dtype=float)
    try:
        cube.resetTransform()
        cube.setTransform(QMatrix4x4(*R.flatten()))
    except Exception:
        pass

def rotate_sensor_to_world(q, ax, ay, az):
    w,x,y,z = q
    R = np.array([
        [1-2*(y*y+z*z), 2*(x*y - w*z), 2*(x*z + w*y)],
        [2*(x*y + w*z), 1-2*(x*x+z*z), 2*(y*z - w*x)],
        [2*(x*z - w*y), 2*(y*z + w*x), 1-2*(x*x+y*y)]
    ])
    return R.dot(np.array([ax, ay, az], dtype=float))

# small helper: median filtering & spike clamp
def median_filter_and_clamp(val_queue, new_val, clamp_abs=None):
    val_queue.append(new_val)
    arr = np.array(val_queue)
    med = np.median(arr)
    if clamp_abs is not None:
        if abs(med) > clamp_abs:
            med = np.sign(med) * clamp_abs
    return med

def is_stationary_windowed(now_t, gyro_sample_deg, acc_world_mag):
    # push window
    zupt_time_window.append(now_t)
    zupt_window.append((np.linalg.norm(gyro_sample_deg), abs(acc_world_mag - 9.81)))
    # compute windowed RMS-like measure
    if len(zupt_window) < 2:
        return False
    gyro_vals = np.array([v[0] for v in zupt_window])
    acc_vals = np.array([v[1] for v in zupt_window])
    # RMS (or mean) check
    return (np.sqrt(np.mean(gyro_vals**2)) < ZUPT_GYRO_THRESH) and (np.mean(acc_vals) < ZUPT_ACCEL_THRESH)

# main update
def update():
    global last_time, q, vel, pos, prev_a_motion, hpf_state, prev_a_hpf, accel_bias_world, gyro_bias

    # read freshest line
    line = None
    while ser.in_waiting:
        try:
            line = ser.readline().decode(errors='ignore').strip()
        except Exception:
            line = None
            break
    if not line:
        return

    parts = line.split(',')
    if len(parts) != 7:
        return
    try:
        t_ms, ax, ay, az, gx, gy, gz = map(float, parts)
    except:
        return

    # timestamps and dt
    if last_time is None:
        last_time = t_ms
        return
    dt = (t_ms - last_time) / 1000.0
    if dt <= 0 or dt > 1.0:
        last_time = t_ms
        return
    last_time = t_ms
    try:
        madgwick.sampleperiod = dt
    except:
        pass

    # median-filter raw sensors and clamp spikes
    ax_f = median_filter_and_clamp(med_ax, ax, clamp_abs=SPIKE_CLAMP)
    ay_f = median_filter_and_clamp(med_ay, ay, clamp_abs=SPIKE_CLAMP)
    az_f = median_filter_and_clamp(med_az, az, clamp_abs=SPIKE_CLAMP)
    gx_f = median_filter_and_clamp(med_gx, gx)
    gy_f = median_filter_and_clamp(med_gy, gy)
    gz_f = median_filter_and_clamp(med_gz, gz)

    # supply gyro to Madgwick in rad/s and subtract estimated bias (in rad/s)
    if GYRO_IN_DEG:
        g_rad = np.radians([gx_f, gy_f, gz_f])
    else:
        g_rad = np.array([gx_f, gy_f, gz_f], dtype=float)
    g_rad_minus_bias = g_rad - gyro_bias

    # update orientation filter
    a_sensor = np.array([ax_f, ay_f, az_f], dtype=float)
    q = madgwick.updateIMU(q, gyr=g_rad_minus_bias, acc=a_sensor)

    # orientation angles
    roll, pitch, yaw = quat_to_euler_deg(q)

    # rotate accel to world
    a_world = rotate_sensor_to_world(q, *a_sensor)

    # update windowed stationarity detection (use raw gyro in deg/s and a_world magnitude)
    gyro_mag_deg = np.linalg.norm([gx_f, gy_f, gz_f])
    acc_world_mag = np.linalg.norm(a_world)
    stationary = is_stationary_windowed(t_ms, np.array([gx_f, gy_f, gz_f]), acc_world_mag)

    # When stationary -> update gyro and accel bias estimates
    if stationary:
        # expected gravity in world: [0,0,9.81]; any difference is accel bias in world frame
        obs_accel_bias = a_world - np.array([0.0, 0.0, 9.81])
        accel_bias_world = BIAS_ALPHA * accel_bias_world + (1.0 - BIAS_ALPHA) * obs_accel_bias
        # gyro bias (we keep in rad/s)
        gyro_bias = BIAS_ALPHA * gyro_bias + (1.0 - BIAS_ALPHA) * g_rad
        # zero velocity update
        vel[:] = 0.0
    # compute motion accel by subtracting gravity and accel bias (both in world frame)
    a_motion = a_world - np.array([0.0, 0.0, 9.81]) - accel_bias_world

    # High-pass filter (per-axis) to remove residual low-frequency bias
    # y[n] = alpha * (y[n-1] + x[n] - x[n-1])
    for i in range(3):
        hpf_state[i] = HPF_ALPHA * (hpf_state[i] + a_motion[i] - prev_a_motion[i])
    a_hpf = hpf_state.copy()

    # trapezoidal integration for velocity
    vel_new = vel + 0.5 * (prev_a_hpf + a_hpf) * dt

    # smoothing on velocity (exponential)
    vel = VEL_SMOOTH * vel + (1.0 - VEL_SMOOTH) * vel_new

    # integrate position (trapezoidal on velocity)
    pos = pos + 0.5 * (vel + vel_new) * dt

    # update prevs
    prev_a_motion = a_motion.copy()
    prev_a_hpf = a_hpf.copy()

    # store buffers for plotting
    t_s = t_ms / 1000.0
    t_buf.append(t_s)
    ax_buf.append(ax_f); ay_buf.append(ay_f); az_buf.append(az_f)
    gx_buf.append(gx_f); gy_buf.append(gy_f); gz_buf.append(gz_f)
    roll_buf.append(roll); pitch_buf.append(pitch); yaw_buf.append(yaw)
    px_buf.append(pos[0]); py_buf.append(pos[1])

    # update plots
    curve_ax.setData(list(t_buf), list(ax_buf)); curve_ay.setData(list(t_buf), list(ay_buf)); curve_az.setData(list(t_buf), list(az_buf))
    curve_gx.setData(list(t_buf), list(gx_buf)); curve_gy.setData(list(t_buf), list(gy_buf)); curve_gz.setData(list(t_buf), list(gz_buf))
    curve_roll.setData(list(t_buf), list(roll_buf)); curve_pitch.setData(list(t_buf), list(pitch_buf)); curve_yaw.setData(list(t_buf), list(yaw_buf))
    curve_xy.setData(list(px_buf), list(py_buf))
    try:
        cube_set_quat(q)
    except Exception:
        pass

# start timer
timer = QtCore.QTimer()
timer.timeout.connect(update)
timer.start(GUI_UPDATE_MS)
app.exec()
```

## 4) Practical tuning & next steps (how to improve more, in order)

1. **Calibrate sensor offsets & scale** on startup: compute average gyro and accel when physically still for \~5 seconds and seed `gyro_bias` and `accel_bias_world`. That reduces initial transient.
2. **Tune ZUPT thresholds**: gather sample traces of stationary & moving, compute RMS values and set thresholds using statistics (mean + 2σ).
3. **If possible, add a magnetometer** (MPU9250 or an external HMC5883/AK8963). That will significantly reduce yaw drift and therefore gravity subtraction errors.
4. **Move gesture detection to features**: compute short-window features (mean, std, peak counts, RMS, quaternion delta, angular velocity energy). Train a small classifier (RandomForest/SVM) or use template matching (DTW) — this will be much more robust than relying on absolute positions.
5. **Consider an EKF that estimates biases**: if you need better continuous position, implement an EKF state like `[p, v, q, bg, ba]` with process models and ZUPT as measurement updates — that’s a longer but powerful path.
6. **Record logged sessions** (raw sensor and timestamps) and run offline analysis to tune filters and thresholds. Use that to build a supervised gesture dataset.

## 5) Short code-level notes / gotchas in the original script

* `vel = VEL_SMOOTH * vel + (1 - VEL_SMOOTH) * vel` was a no-op; it has been fixed.
* HPF had a placeholder line and used `prev_a_world` name confusingly. It is replaced with explicit `prev_a_motion` and explicit HPF formula.
* Consistent units: keep gyro units consistent (deg/s for ZUPT checks, rad/s for Madgwick). The revised script enforces this.
* Bias subtraction: estimate accel bias in world frame and remove when computing motion acceleration.

## 6) Gesture-tracking suggestions (concrete)

* **Segmentation**: Use ZUPT / activity windowing to split gestures. ZUPT gives ready segmentation boundaries.
* **Features** (per window): mean/std of accel and gyro, peak magnitude, quaternion delta, angular velocities RMS, duration, zero crossings, PCA on acceleration axes.
* **Classifiers**: start with DTW (template matching) for small gesture sets; if you collect labeled data, use RandomForest or a tiny neural net.
* **Online constraints**: after classifying, use short dead-zone (no overlapping gestures) and require min-duration to avoid false positives.
